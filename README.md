# Pandas Practice

A collection of Jupyter notebooks for learning and practicing the core concepts of [pandas](https://pandas.pydata.org/), Python's data analysis library.

## Contents

| Notebook | What it covers |
|----------|----------------|
| [`Series.ipynb`](Series.ipynb) | Creating and working with pandas Series: indexing, labels, operations |
| [`DataFrames.ipynb`](DataFrames.ipynb) | Creating DataFrames, selecting rows and columns, adding and dropping data, conditional filtering |
| [`MissingData.ipynb`](MissingData.ipynb) | Detecting, dropping and filling missing values (NaN) |

## Getting Started

### Prerequisites


- Python 3.8 or higher
- pip
- Jupyter Notebook or JupyterLab

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Pricodin/pandas-practice.git
   cd pandas-practice
   ```

2. (Optional) Create and activate a virtual environment:

   ```bash
   python -m venv venv
   source venv/bin/activate      # On Windows: venv\Scripts\activate
   ```

3. Install the dependencies:

   ```bash
   pip install pandas numpy jupyter
   ```

4. Launch Jupyter:

   ```bash
   jupyter notebook
   ```

5. Open any `.ipynb` file and run the cells in order.

## Suggested Learning Order

1. **Series**: the one-dimensional building block of pandas
2. **DataFrames**: two-dimensional, table-like data
3. **MissingData**: cleaning real-world, incomplete data
